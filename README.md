# osseco/.github

The public profile for the [osseco](https://github.com/osseco) organization.

- [`profile/README.md`](profile/README.md) is shown on the organization page to everyone.
- [`profile/assets/`](profile/assets/) holds the light and dark banners. Their colors are the tokens from the [osseco web design guide](https://github.com/osseco/web-design-guide/blob/main/docs/tokens.md); keep them in sync with the favicon on [osseco.github.io](https://github.com/osseco/osseco.github.io).

The members-only profile lives in [`osseco/.github-private`](https://github.com/osseco/.github-private).

When a project joins or leaves osseco, update the projects table here, in `.github-private`, and in `src/data/projects.ts` on the site.
