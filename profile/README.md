OSSEco builds and curates what sits around the code: how companies contribute, how dependencies stay safe, how projects ship and look.

**[osseco.github.io](https://osseco.github.io/)** · [Projects](https://osseco.github.io/projects) · [Curated lists](https://osseco.github.io/lists) · [Contribute](https://osseco.github.io/contribute)

### Projects

| Project | What it does |
| --- | --- |
| [git-uplink](https://github.com/npetzall/git-uplink) | A git subcommand for building on a public project from a private fork: keep unreleased work internal, gate it through IP review, and contribute upstream. |
| [cargo-project-tools](https://github.com/osseco/cargo-project-tools) | Install a project's cargo tools from its own Cargo.lock files, so you can audit them and patch vulnerable dependencies without waiting for a release. |
| [setup-cargo-project-tools](https://github.com/osseco/setup-cargo-project-tools) | A GitHub Action that installs cargo-project-tools, builds the project's tools into an Actions cache and audits their locks. |
| [setup-sfw-free](https://github.com/osseco/setup-sfw-free) | A GitHub Action that installs Socket Firewall Free, verified against pinned checksums, so package installs block malicious packages. |
| [web-design-guide](https://github.com/osseco/web-design-guide) | One look for every osseco web frontend: tokens, components, starter templates and a Pages workflow. |

### Get involved

Propose a list entry, start a new list, or bring a project to osseco: see [how to contribute](https://osseco.github.io/contribute). Report security issues privately through **Security → Report a vulnerability** on the affected repository.
